1. 服务内容

1.1 本游戏为使用虚幻引擎（Unreal Engine）开发的电子游戏。具体玩法、内容、支持设备和运行要求以您实际取得的游戏版本及游戏内说明为准。

1.2 游戏可能需要访问网络以提供广告等相关功能。网络条件、系统版本和设备性能可能影响部分功能的使用。

1.3 我们会合理维护和改善服务，并通过游戏内提示、官方网站或发行渠道发布重要更新信息。

2.2 您不得利用本游戏实施违法活动，或者故意干扰本游戏、其他用户及相关网络服务的正常运行，包括通过恶意程序、未经授权的攻击或作弊手段破坏服务安全与公平性。

2.3 未经合法授权，不得以侵犯知识产权的方式复制、销售、传播或修改本游戏及其受保护资源。本条不限制法律允许的合理使用及其他法定权利。

2.4 对于严重违反本协议、危及服务安全或侵犯他人合法权益的行为，我们可在合理、必要且符合法律规定的范围内采取纠正措施，并依法保障用户的合法权益。

3. 游戏数据与虚拟内容

3.1 为实现游戏功能，应用可在设备本地保存进度、设置等必要数据。清除应用数据、卸载应用或更换设备可能导致未备份的数据无法恢复，请在操作前注意相关风险。

3.2 游戏内的进度、积分、道具及其他虚拟内容（如实际提供），仅供按游戏规则使用；除法律另有规定或我们作出明确承诺外，不当然具有现金兑换价值。

3.3 对于因程序故障产生的数据异常，我们会根据技术条件和实际情况采取合理的修复措施。涉及依法应予保障的用户权益时，按照适用法律处理。

4. 广告及第三方服务

4.1 本游戏接入穿山甲广告 SDK，由北京巨量引擎网络技术有限公司提供广告投放及相关技术服务。广告可能通过第三方服务加载，具体展示方式以游戏实际版本为准。

4.2 第三方广告的展示、点击和播放可能受到网络状况、设备状态及服务商技术条件影响。涉及游戏内广告奖励的，以实际公布的活动或功能规则为准。

4.3 点击广告后进入的第三方网站或应用，可能由相应第三方独立提供服务，相关交易及信息处理应遵守其规则。我们依法承担自身应承担的义务。

4.4 穿山甲广告 SDK 的个人信息处理情况，请查看本游戏《隐私政策》及穿山甲广告 SDK 隐私政策。
