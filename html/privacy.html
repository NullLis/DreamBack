欢迎访问 DreamBack《仙冢》项目网站及使用对应游戏。本隐私政策由深圳市梦新技术工作室（个人独资）（以下简称“我们”）提供，说明与本项目有关的个人信息处理、第三方服务及用户权利。

现有公开仓库包含项目介绍、更新日志、下载信息及反馈入口，但未提供可验证的正式游戏安装包、第三方 SDK 集成清单或运行时权限清单。因此，下文对已知网站活动作具体说明；涉及尚未核实的客户端处理活动，不会推断为已发生或承诺为未发生。

在正式发布包含个人信息处理功能的客户端前，需要依据实际安装包、Android 权限、SDK 初始化和网络请求情况，补充并公布准确的客户端信息处理清单。本网页文字不能替代对真实运行行为的核验。

如有疑问，请使用本政策末尾的联系方式联系我们。

1. 我们可能收集的个人信息

根据您实际使用的功能，可能涉及以下类别：

  • 网站访问数据：访问 GitHub Pages 托管的网站时，托管平台可能处理 IP 地址、访问时间、请求路径、浏览器或设备信息，用于传输页面内容、维护安全及排查故障。具体由托管服务商依其政策处理。
  • 主动提交的反馈：如果您通过 GitHub Issues 或电子邮件联系我们，我们可能收到您主动提供的账号昵称、电子邮箱、问题描述、附件及必要的沟通记录，用于回复和解决问题。
  • 游戏本地数据：客户端如具有本地存档功能，可能在设备上保存设置、游戏进度等数据。此类数据是否上传、同步或备份，需以对应安装包实际实现和随版本提供的说明为准；本地保存不等于自动向开发者上传。
  • 客户端权限和第三方 SDK 数据：目前公开仓库没有可供核验的正式客户端权限及 SDK 处理清单，因此不能在此准确列举其实际采集字段。正式客户端发布前须按实际情况披露每项权限、信息类别、使用目的、第三方名称及处理方式。

仅凭 Unreal Engine、Android 平台或项目名称，不能推断游戏必然采集设备标识、定位、通讯录或广告数据。具体以客户端实测及公开的 SDK 清单为准。

2. 我们如何使用您的个人信息

我们仅在提供相应功能、回应您主动提出的请求、维护服务安全和履行法律义务所需的范围内处理已取得的信息，例如：

  • 通过托管平台向浏览器交付网页、保证基本可访问性与安全性；
  • 接收、核实并回复您主动提交的错误报告、问题反馈和支持请求；
  • 依法处理个人信息访问、删除、更正或其他隐私权利请求；
  • 如未来游戏版本需要账号、在线服务、广告、支付或分析功能，在启用前说明相应目的、数据类型、处理依据及退出方式。

我们不会因为您仅访问项目介绍页面而要求您主动提供姓名、身份证号码或手机号码。若未来新增需要此类信息的功能，应另行告知并依法处理。

3. 我们如何存储和保护您的个人信息

网站数据：由 GitHub Pages 等实际提供网站托管的服务商依据其服务规则确定相关日志的存储地点、期限和安全措施。我们无法代表托管平台对其具体保存期限作出承诺。

主动反馈数据：我们可能在处理咨询、故障及其他合法事务所必需的期限内保存您提供的邮件、Issue 和附件；问题结束后按适用法律与实际需要进行清理、删除或匿名化处理。

本地数据：如客户端保存游戏数据，其存储和删除方式由游戏实际版本、操作系统及可能启用的备份机制决定；清除数据或卸载应用可能导致记录丢失。

我们将采取与实际处理活动相适应的访问权限管理和安全措施，努力降低未经授权访问、披露、篡改或丢失的风险，但互联网服务不能保证绝对安全。

4. 我们如何对外提供您的个人信息

当前公开网站依赖以下已知第三方服务：

  • GitHub / GitHub Pages：用于仓库托管、网页提供及 GitHub Issues 反馈。参见 GitHub 隐私声明。
  • 电子邮件服务：当您主动发送邮件时，电子邮件服务提供方可能按照其服务条款处理邮件地址、正文和附件。

第三方 SDK 披露：本项目的公开网页文件无法证明客户端是否使用穿山甲、Tap、QooApp、统计、支付或其他 SDK，因此本页面不会将任何未经核实的第三方 SDK 认定为已由《仙冢》接入。若游戏实际接入此类服务，应在客户端上线前补充服务商全称、SDK 名称、目的、信息类型、处理方式和隐私政策链接，并依法履行必要的告知或同意程序。

除法律规定、取得必要授权或提供您主动请求的服务确有必要的情形外，我们不会擅自出售或公开披露您直接提交的个人信息。

5. 我们如何使用 Cookies 及相关技术

本项目目前公开的静态网页源码未显示专为本站设置的广告个性化跟踪脚本或 Cookie 逻辑；不过浏览器、托管平台及外部链接仍可能使用缓存、Cookie 等技术提供和维护服务，具体依相关服务提供方政策处理。

您可以通过浏览器设置清除或限制 Cookie。请注意，网页 Cookie 与游戏客户端可能使用的本地存储、第三方 SDK 标识或设备权限并不是同一种机制。

若未来接入网站分析、登录或其他会改变信息处理范围的功能，我们将及时更新本政策并履行必要程序。

6. 我们如何保护未成年人的权益

我们重视未成年人的隐私与安全。未成年人应在监护人指导下阅读本政策，并按照适用法律要求取得必要的监护人同意。

如后续客户端面向儿童或提供广告、支付、社交等功能，我们将根据其实际用户群体和法律要求采取额外保护措施，并在上线前完善相应的隐私告知与使用规则。

如监护人认为未成年人的信息被不当处理，可通过第 9 章的联系方式提出请求，我们将核实并依法处理。

7. 您对个人信息享有的权利

在适用法律允许的范围内，您可能享有知情、访问、复制、更正、删除、撤回同意、限制或拒绝处理等权利。

  • 主动反馈数据：您可以通过邮件请求访问、更正或删除与您有关的沟通资料；对 GitHub Issues 中的公开内容，删除或编辑还可能受平台规则限制。
  • 本地游戏数据：可以根据实际系统和客户端设置清除应用数据或卸载应用，但请注意可能无法恢复的进度损失。
  • 第三方平台数据：对 GitHub 或邮件服务商自行处理的数据，您可使用其提供的隐私权利渠道。
  • 撤回同意：对于以您的同意作为处理依据的事项，您可依实际客户端提供的隐私管理入口或通过邮件提出请求；撤回不影响此前依法完成的处理。

我们会在核实身份和具体请求后，依据适用法律在合理期限内处理，并说明需要第三方配合的事项。

8. 本政策如何变更

随着游戏开发、网站功能调整、客户端发布、第三方服务变化或法律法规更新，我们可能修订本政策。

更新后的政策会在页面标明更新日期。若变更对用户权益产生重大影响，我们将按法律要求通过适当方式提示，并在需要时重新取得同意。

游戏正式发布前，应完成一次针对实际安装包和全部第三方 SDK 的披露复核，确保本政策与实际运行情况一致。
