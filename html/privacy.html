DreamBack《仙冢》个人信息保护说明

更新日期：2026年11月13日

DreamBack《仙冢》（以下简称“本游戏”）由深圳市梦新技术工作室（个人独资）（以下简称“我们”）提供。本政策适用于本游戏及其项目网站，说明在提供相关服务时涉及的个人信息处理方式及您的权利。

本游戏使用虚幻引擎（Unreal Engine）开发，并接入穿山甲广告 SDK。穿山甲作为第三方广告技术服务商，可能依据其服务功能处理设备及广告相关信息。我们遵循合法、正当、必要原则处理个人信息；依法需要取得同意的处理活动，将依法向您告知并获取相应同意。

1. 我们处理的信息

本地游戏数据。为保存游戏进度、使用偏好或设置，游戏可在设备本地存储相应数据。仅在设备本地保存不等于这些数据被自动上传。

您主动提交的信息。当您通过邮件或 GitHub Issues 反馈问题时，我们可能收到您提供的邮箱地址、反馈内容、截图和其他材料，用于回复及处理请求。请勿在公开反馈页面提交身份证件、账号密码等敏感信息。

网站访问信息。当您访问本项目的 GitHub Pages 网站时，网站托管及网络服务提供方可能处理 IP 地址、请求时间、浏览器或设备信息等必要访问记录，用于页面交付、安全防护和故障排查。该类信息由相应服务提供方依据其规则处理。

广告相关信息。游戏接入的穿山甲广告 SDK 在提供广告服务时会处理下文第 3 节所列的信息。

2. 信息处理目的与方式

我们仅在提供游戏服务、维护正常运行、回应用户反馈和履行法定义务所需的范围内处理相应信息。涉及穿山甲的广告服务，主要用于广告加载与展示、监测归因、统计分析、反作弊以及故障诊断。

广告相关信息可由穿山甲 SDK 通过集成在游戏中的技术组件处理；您主动提供的反馈信息由我们通过相应沟通渠道处理。对于需要另行授权的功能，我们将依据适用法律及您的选择开展处理。

3. 第三方 SDK：穿山甲广告

SDK 名称：穿山甲广告 SDK

提供方：北京巨量引擎网络技术有限公司

使用场景：在游戏中加载、展示广告并提供广告监测及相关技术服务

处理方式：由 SDK 按其功能和配置采集或处理相关数据

官方政策：https://www.csjplatform.com/privacy/partner

依据穿山甲广告 SDK 公开的 Android 端信息类别，广告服务涉及：

  • 设备信息：品牌、型号、系统版本、屏幕密度与分辨率、设备语言和时区、SIM 卡运营商代码、CPU、可用存储空间，以及 Android ID、OAID 等设备标识。
  • 网络信息：IP 地址、运营商信息、Wi-Fi 状态与网络信号强度。
  • 应用信息：应用包名、版本号、运行进程及前后台状态。
  • 广告交互与性能数据：广告展示、点击、转化记录，以及崩溃、性能诊断信息。

穿山甲公开政策还列明若干可选数据类别，例如仅适用于具备相关服务的 Android 设备的 GAID、应用列表、特定传感器信息，以及粗略或精确位置相关信息。这些项目是否处理，取决于实际集成版本、启用的广告功能、系统权限与相应授权条件，不属于所有设备的必然收集项目。

在启用个性化广告推荐功能时，SDK 可能根据广告交互及设备相关信息进行个性化推荐。您可通过设备支持的广告隐私设置以及下文提供的联系方式提出管理相关信息处理的请求。

4. 权限与用户选择

游戏如需调用系统权限，我们会依据相应功能用途及系统要求向您说明并请求授权。您可在设备系统设置中查看或管理应用权限。拒绝与游戏基本功能无关的可选权限，不应影响基本功能的正常使用。

同意本政策不代表您已授予所有系统权限。依法以同意为依据处理个人信息时，您有权撤回同意；撤回不影响此前依据有效同意所进行处理的合法性。

5. 信息保存与安全保护

游戏进度、设置等本地数据的存储通常与设备上的应用数据相关。您可通过清除应用数据或卸载应用处理此类数据，但相关操作可能导致进度丢失；系统备份功能可能影响实际保留情况。

您主动提供的咨询和反馈信息，仅在处理相关事务及履行必要法定义务所需期间保存，并在不再需要时依法删除或匿名化。网站访问日志和穿山甲 SDK 所处理的数据，其存储地点及期限分别受相应服务提供方的服务和隐私规则约束。

我们将根据实际处理活动采取合理的访问控制、权限管理和必要的安全保护措施，防止未经授权的访问、泄露、篡改或丢失。

6. 第三方提供与外部链接

我们不会出售您的个人信息。为实现广告功能，穿山甲广告 SDK 按本政策第 3 节及其官方隐私政策处理相关数据；在法律要求单独同意的情况下，我们将依法履行相应告知和同意程序。

本项目网站由 GitHub Pages 提供托管。您点击外部链接、访问 GitHub 仓库或在 GitHub Issues 留言时，相关信息可能由 GitHub 根据其隐私声明处理。网络访问可能涉及境外服务设施。

除法律规定或者依法完成必要程序的情况外，我们不会擅自向其他独立第三方提供或公开披露您的个人信息。

7. 您的个人信息权利

在适用法律规定的范围内，您可以请求了解、查阅、复制、更正或删除我们处理的个人信息，并可要求解释处理规则、撤回基于同意的授权。

您可以通过设备的应用权限设置管理系统授权；如需处理您提交的反馈资料，或提出与穿山甲广告数据有关的请求，可发送邮件至316697487@qq.com。我们会核实您的请求，在法律规定的期限内答复；涉及第三方独立处理的数据时，我们会提供必要的联系协助或处理指引。

为保护您的数据安全，我们可能在处理请求前采取合理措施核实申请人与相关信息的关系。

8. 未成年人保护

我们重视未成年人的个人信息保护。未成年人应当在监护人指导下使用本游戏，并遵守适用的未成年人网络保护要求。

处理不满十四周岁未成年人的个人信息时，我们将依法取得其父母或其他监护人的同意并采取适当保护措施。监护人如需查询、删除相关信息，可通过第 9 节的联系方式提出请求。

9. 政策更新与联系我们

如游戏功能、第三方服务或个人信息处理方式发生变化，我们会及时更新本政策，并在页面标明更新日期；涉及依法应重新取得同意的变化时，我们会履行相应程序。
