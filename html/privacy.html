引言与适用范围

欢迎使用 DreamBack《仙冢》（以下简称“本游戏”）及相关网站。本游戏由深圳市梦新技术工作室（个人独资）（以下简称“我们”或“开发者”）开发和提供。本政策旨在说明游戏客户端、网站以及已集成第三方组件可能如何处理个人信息，并介绍您依法享有的权利。

本游戏使用 Unreal Engine（虚幻引擎） 开发，并且已接入穿山甲广告 SDK。在实际启用广告服务时，穿山甲可能按其功能和配置处理设备、网络、广告交互及诊断相关信息。我们会依照适用法律履行告知、必要授权和最小化配置义务。

使用虚幻引擎是游戏技术实现方式，不意味着游戏会仅因使用引擎就自动向 Epic Games 上传玩家个人信息。如实际游戏另行接入 Epic Online Services、Crash Reporter、分析服务等，我们应依据对应组件和实际数据流另行披露。

本政策对已确认使用的技术作出明确披露。由于本网站仓库没有可独立核验的游戏安装包和完整运行时权限清单，实际涉及哪些可选信息、SDK 版本、广告类型、权限、网络请求及同意机制，仍须以发布版本的实际集成配置和测试结果逐项核实。本政策并不表示以下列举的全部可选字段均被实际收集。

本政策遵循合法、正当、必要和透明的原则。有关穿山甲广告 SDK 的独立处理规则，您也可以查阅其官方隐私政策。

1. 我们可能收集的个人信息

根据您实际使用的游戏功能、设备环境以及已集成第三方服务的版本与配置，可能涉及以下个人信息：

  • 本地游戏数据：游戏进度、设置和其他用于恢复运行状态的信息可能保存在设备本地；本地保存不代表自动上传给开发者。具体备份或同步方式以游戏实际功能为准。
  • 网站访问与基础日志：当您访问 GitHub Pages 上的相关页面时，网站托管方可能处理 IP 地址、请求时间、访问路径、浏览器及设备类型等信息，以完成网页传输、保障服务安全和排查故障。
  • 穿山甲广告 SDK 的设备基础信息：本游戏已集成穿山甲广告 SDK。根据穿山甲官方政策，SDK 在实际启用相关服务时可能处理设备品牌、型号、操作系统版本、屏幕密度和分辨率、设备语言与时区、CPU、可用存储空间、SIM 卡运营商代码等信息，以及 Android ID、OAID 等设备标识，用于广告展示、投放监测、归因及反作弊。
  • 网络信息：广告服务可能处理 IP 地址、运营商信息、Wi-Fi 状态、网络信号强度等，用于网络连接、服务稳定性、广告投放和风险控制。
  • 由版本和配置决定的可选信息：部分 SDK 版本或功能配置可能涉及 GAID、SSID、BSSID、应用安装或使用情况、设备传感器、粗略或精确位置等；某些历史版本还可能涉及 IMEI、IMSI、MEID、ICCID、设备 MAC 地址等标识。这些并非《仙冢》当前安装包必然采集的字段，实际是否处理须结合所用穿山甲版本、SDK 可选开关、设备权限与用户授权核验。
  • 广告交互与诊断信息：如启用相应广告功能，穿山甲可能处理广告展示、浏览、点击、转化、应用包名、版本与前后台状态、崩溃或性能诊断等信息，用于效果统计、广告反作弊及服务稳定性。
  • 主动提交的反馈：当您通过电子邮件、GitHub Issues 联系开发者时，我们可能收到您提供的邮箱、公开用户名、问题描述、截图、附件及沟通记录，用于处理问题。公开 Issue 的内容可能被其他访问者看到，请勿提交不必要的敏感信息。

SDK 的实际采集范围会随版本、功能及操作系统变化。具体信息类别与可选范围请查阅穿山甲广告 SDK 隐私政策及其合规使用说明。上述可能收集的信息范围并不代表用户已授权所有数据处理。

2. 我们如何使用您的个人信息

在适用法律允许的范围内，开发者及相关服务提供方可能基于相应服务目的处理必要信息：

  • 提供本游戏的运行、存档或版本支持等已实际启用的功能；
  • 通过穿山甲广告 SDK 实现广告加载与展示、监测归因、投放效果分析、反作弊及服务稳定性保障；
  • 如游戏实际启用个性化广告功能，在履行相应告知及同意或退出机制后，提供相关广告推荐；
  • 通过 GitHub Pages 提供项目网页，维持网络服务和基本安全；
  • 受理并回复您主动提交的问题反馈、支持请求或个人信息权利请求；
  • 履行适用的法律、监管和安全保障义务。

本游戏通过虚幻引擎实现渲染、运行与游戏逻辑。虚幻引擎本身属于技术组件，不能据此认定游戏必然向 Epic Games 提交玩家标识或个人资料。如另外启用 Epic 提供的在线服务、遥测、崩溃上报或账号功能，我们应根据实际情况另行说明其处理的信息与用途。

我们不会因为您仅查看介绍网页而要求主动提交身份证件或手机号码，也不会将您主动提交的反馈邮箱用于与处理反馈无关的营销。对于改变处理目的的情况，我们将依法履行相应程序。

3. 我们如何存储和保护您的个人信息

本地游戏数据：游戏设置、进度等数据如在设备本地保存，其保存和删除方式取决于实际客户端、系统设置与可能启用的备份机制。清除应用数据或卸载游戏可能导致记录丢失。

广告 SDK 数据：穿山甲在提供广告服务时自行处理的信息，其处理规则、保存地点、保存期限、删除及安全措施以穿山甲官方隐私政策及实际服务协议为准。我们将根据实际 SDK 版本与功能配置核实相关数据流。

网站访问数据：由 GitHub Pages 等实际托管方依据其政策处理和保存。我们不能代表托管服务方对日志保存期限作出超出其公开规则的承诺。

反馈资料：对您主动通过邮件或公开反馈入口提交的信息，我们将在回复问题、故障排查、争议处理或履行法律义务所必要的期限内保留，并在适当时间依法删除、匿名化或妥善处理。

我们根据实际处理活动采取合理访问控制、必要技术保护与最小化措施，降低数据被未经授权访问、披露、篡改或丢失的风险，但任何互联网服务都无法保证绝对安全。

4. 我们如何对外提供您的个人信息

我们不会以出售个人信息为目的向第三方提供您主动提交的数据。为提供《仙冢》游戏及相关网站服务，目前已确认涉及以下第三方技术或平台：

穿山甲广告 SDK（已接入）

  • SDK 名称：穿山甲广告 SDK
  • 服务提供方：北京巨量引擎网络技术有限公司
  • 主要用途：广告投放与展示、广告监测归因、投放效果统计、反作弊、服务稳定性保障；个性化广告属于取决于配置的扩展功能。
  • 处理方式：SDK 在启用相关功能时可能自行采集必要的设备、网络、广告交互和诊断信息；部分数据可能用于与广告合作方的必要业务协作，以其实际政策和配置为准。
  • 可能涉及的信息：设备品牌、型号、系统版本、屏幕信息、Android ID、OAID、网络状态、运营商信息及广告交互记录；GAID、应用列表、位置、Wi-Fi 网络标识、传感器等部分字段可能取决于 SDK 版本、启用的功能和授权情况。部分旧版本还可能涉及 IMEI、IMSI、MAC 等标识。请勿将这些可选字段理解为本游戏全部已采集。
  • 隐私政策：https://www.csjplatform.com/privacy/partner

Unreal Engine（虚幻引擎，已使用）

  • 技术提供方：Epic Games
  • 用途：游戏开发、引擎运行、渲染和其他底层技术功能。
  • 个人信息说明：使用引擎本身并不能证明游戏自动向 Epic Games 上传终端用户的个人信息。目前未确认《仙冢》是否另外启用 Epic Online Services、Epic 账号、引擎遥测或崩溃上报相关组件；如启用，我们将根据实际处理情况补充披露。
  • GitHub / GitHub Pages：用于公开仓库、项目页面及 GitHub Issues 反馈。参见 GitHub 隐私声明。
  • 电子邮件服务：在您主动发送邮件时，相关邮件服务提供方可能按其规则处理邮件地址、正文和附件。

除法律法规要求、履行必要服务或取得所需授权外，我们不会擅自向其他第三方提供或公开披露个人信息。其他 SDK（例如登录、支付、数据分析或崩溃上报组件）如实际接入，将另行核实并依法披露。

5. 我们如何使用 Cookies 及相关技术

Cookie 是网站可能存储在浏览器中的小型数据文件。目前《仙冢》公开的静态网站本身未实现账号登录或跨站广告跟踪脚本。浏览器、GitHub Pages 等托管平台及外部网站可能使用 Cookie、缓存和必要的安全技术，具体以其规则为准。

您可通过浏览器设置清理或限制 Cookie。但网页 Cookie 与 Android 游戏内的穿山甲广告 SDK、设备标识、系统权限以及本地游戏存档不同，清除浏览器 Cookie 并不能清除游戏内广告 SDK 或存档数据。

如未来网站添加登录、分析或其他会改变信息处理范围的功能，我们会相应更新本政策。

6. 我们如何保护未成年人的权益

我们重视未成年人的个人信息保护。未成年人应在监护人指导下阅读本政策，并根据适用法律要求取得监护人同意。

本游戏已集成穿山甲广告 SDK。我们应根据游戏适用年龄、发行区域和适用法律要求配置广告功能，针对未成年人采取必要的隐私保护和广告展示措施，并履行适用的防沉迷或其他管理义务。对于依法需要监护人同意或限制的处理行为，应采取相应措施。

如监护人认为未成年人的个人信息被不当处理，可通过本政策第 9 章的联系方式与我们联系，我们将核实并依法处理。

7. 您对个人信息享有的权利

根据适用法律，您可能依法享有知情、访问、复制、更正、删除、限制或拒绝处理个人信息、撤回同意等权利。

  • 管理本地数据：您可通过客户端实际提供的功能，或系统的清除应用数据、卸载应用等方式处理本地数据；这可能导致未备份的游戏进度无法恢复。
  • 管理主动提交的信息：您可通过电子邮件向我们申请访问、更正或删除您主动提供的反馈资料。对公开发布在 GitHub Issues 的内容，修改和删除可能受 GitHub 规则限制。
  • 广告数据与个性化广告：若本游戏实际开启穿山甲个性化推荐，我们将依适用法律提供相应的告知和拒绝或关闭途径，并在需要时协调 SDK 服务提供方处理您的数据请求。穿山甲相关权利请参阅其官方隐私政策。
  • 撤回同意：对于以同意作为处理依据的活动，您可使用实际提供的隐私管理入口或联系开发者提出请求。撤回不会影响撤回之前依法开展的处理。

我们将在合理期限内依法核实并处理您的请求；若需要第三方配合，会向您说明必要程序。

8. 本政策如何变更

我们可能因游戏功能更新、穿山甲 SDK 版本或配置变化、其他第三方服务调整、技术发展以及适用法律法规的要求，适时修订本隐私政策。

修订后会在相关网站或游戏内以适当方式公布新版本及更新日期。对于对您权益产生重大影响的变更，我们将依照法律要求予以提示，并在必要时重新取得同意。

我们将持续核对《仙冢》实际发布的安装包、已启用的穿山甲 SDK 版本及权限配置，确保数据处理披露与实际情况相符。
